# Project Summary

## Project Title
Sales Performance & Revenue Growth Dashboard

## Objective
To analyze sales data using Microsoft Power BI and create an interactive dashboard for monitoring revenue, profit, sales targets, products, regions, and sales channels.

## Tools Used
- Microsoft Power BI Desktop
- Power Query
- DAX (Data Analysis Expressions)
- CSV dataset

## Work Completed
- Imported sales data into Power BI.
- Created KPI cards for revenue, profit, units sold, target sales, and profit margin.
- Built a revenue trend chart.
- Analyzed revenue by product category and region.
- Created a Top 5 Products by Revenue pie chart.
- Created a Sales Channel Distribution donut chart.
- Built a Target Sales vs Actual Sales chart.
- Created a Region Performance Matrix.
- Analyzed sales executive performance.
- Added interactive region, product category, sales channel, and date slicers.
- Prepared screenshots and project documentation.

## Skills Demonstrated
- Data visualization
- Business intelligence
- Data analysis
- Power Query data preparation
- DAX measures
- KPI reporting
- Dashboard design
- Business performance analysis

## Business Applications
This type of dashboard can help sales and business teams monitor performance, compare regions, identify high-performing products, and track progress toward sales targets.

## Project Limitations
This is an educational portfolio project. The findings depend on the dataset used and should not be treated as verified business results.
