# Sales Performance & Revenue Growth Dashboard

## Project Overview
This project analyzes sales performance using Microsoft Power BI. The dashboard helps users monitor revenue, profit, units sold, target achievement, product performance, regional sales, and sales channel distribution.

## Objectives
- Track total revenue and profit.
- Monitor sales targets and achievement.
- Analyze revenue trends over time.
- Compare product categories and regions.
- Evaluate sales executive performance.
- Support data-driven business decisions.

## Tools & Technologies
- Microsoft Power BI Desktop
- Power Query for data preparation
- DAX for measures and calculations
- CSV dataset for sales analysis

## Dashboard Features
- KPI cards for revenue, profit, units sold, target sales, and profit margin.
- Revenue trend analysis.
- Region-wise and category-wise revenue analysis.
- Top 5 products by revenue.
- Sales channel distribution.
- Target sales versus actual revenue comparison.
- Region performance matrix.
- Sales executive performance analysis.
- Interactive region, category, channel, and date filters.

## Dataset
The project uses a sales dataset containing fields such as date, region, product category, product name, units sold, revenue, cost, profit, target sales, and sales channel.

## Business Value
This dashboard demonstrates how business intelligence can help organizations identify high-performing products, compare regional performance, monitor targets, and make informed sales decisions.
