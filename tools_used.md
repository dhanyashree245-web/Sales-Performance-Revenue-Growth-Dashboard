# Tools and Technologies Used

## Microsoft Power BI Desktop
Used to build interactive dashboard pages, KPI cards, charts, slicers, and a performance matrix.

## Power Query
Used to import and prepare the sales dataset.

## DAX
Used to create measures and calculate business performance indicators, including total revenue, total profit, units sold, profit margin, target achievement, and revenue growth.

## CSV Dataset
Used as the data source for sales performance analysis.

## GitHub
platform used for publishing the project, documentation, screenshots, and Power BI report file.
